# P8 visualizations

Generated by `python run.py p8-viz --stage {a,b,cd}` from saved P8 records only. Sources: `runs/p8/a` (P8a checkpoints, results), `runs/p8/b` (funnel, mixing), `runs/p8/collection` (teacher records, recorded witnesses), `runs/p8/c_training` (rankings, hash `sha256:5d2f9238...`), `runs/p8/execution` (P8d episodes, their own recorded arrays).

## Label legend

- **NEW P8d ONE-SHOT (recorded)** / **VERIFIED - recorded teacher witness**: motion replayed from stored arrays of that exact run.
- **TARGET_CERTIFIED_INFEASIBLE / UNRESOLVED_CENSORED / ABSTAINED - NO TRACE**: no motion drawn.
- **ORACLE-REVEALED DIAGNOSTIC, NOT AVAILABLE TO ROBOT**: offline conditional completion with ground-truth bits revealed.
- `factor_graph_modes.png` is a diagram of the code, not a learned graph.
