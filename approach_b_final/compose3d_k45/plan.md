# Frozen short-horizon composition in 3D: K4/K5 pilot
**Implementation and experimental contract v1.0 | 25 November 2026**

## 0. Objective and scope

Determine whether the existing frozen 3D task-conditioned cVAE and X/Y Boltzmann scorer, trained on repairs of length at most three, can be reused at inference to solve four- and five-relocation problems. Study only **10 K4 and 10 K5 fresh 3D scenes**. This is an exploratory proof of concept, not a large benchmark or independent superiority claim. If minimum K cannot be certified, distinguish witnessed length from certified minimum; never silently relabel. No MCTS, model training/fine-tuning, auxiliary losses, calibration, new training interventions, 2D experiments, K6+ or baseline-repository changes. Teacher calls are allowed only for approved scene construction/certification and evaluation, never for learner decisions. Keep historical K≤3 results intact. No external baseline replication in this pilot.

Five required pipelines: B0 original K≤3; B1 direct K≤5 extrapolation; B2 sequential local replanning; B3 global set construction plus short-horizon execution composition; B4 Fig. 3(a) recursive task retargeting and insertion with the B3 final composition scorer. B4 vs B2 diagnoses insertion, and B4 vs B3 diagnoses recursive candidate discovery; these comparisons are not single-factor causal claims because construction differs. Include matched-candidate diagnostics below. No claim that any new pipeline works before physical checks.

## 2. Public action grammar, views and score semantics

Let S0 contain all objects including original target T0, goal G0, original occupied cells O0 and q_ref. One corrective action `(object index, destination cell)` relocates one non-target object to a distinct support cell. Public max length 5 for B1–B4; B0 max 3. Original target never displaced during repairs. Each object at most once globally. Destinations initially empty, currently empty, not G0, distinct across global sequence. All geometry/attributes of stationary objects retained. No swaps, stacking, vacated-cell use, moving twice, or changing robot geometry. This restriction is shared across all methods and scene certification; report if it prevents solutions. Do not silently introduce dynamic vacated cells. No artificial immovable flag in 3D attrs (index 3 is height, index 4 is target flag).

`rebase(S0,P,task=None,reserved_objs=(),reserved_cells=())`: copy public record; apply hypothetical prefix P to `cells0` and `xy0`, preserve original object order/ids, geometry, all objects and reference pose. For original task retain ctx/target flags. For temporary task `(A,d)`, change tid, goal_cell, goal xy, one-hot target attribute at index 4 for **all** objects, and ctx goal xy and target size/height/is_box; keep q_ref sin/cos. Reconstruct task features via frozen sampler. Do not use original `t0` id as new target name in learned view; preserve index-to-id map. Ensure original task's target remains reserved, originally occupied cells remain forbidden even after rebasing, original goal and temporary goal and all pending reserved destinations forbidden for *enabling* moves. Pending objects, already moved objects and current task target excluded from relocation choices, never from scene encoding. Only release own reservation when executing its pending action; no duplicate or goal collision. A temporary task is the action pick A from its current source and place A at d, not merely making cell d empty. Retargeted Y models are OOD on temporary tasks; report, do not claim semantics imply accuracy.

S1 proposals: call `propose_many` with archived top6 and retain top4 on appropriate current root/task. B0/B1/B3 use original proposals D4(S0); B2/B4 requery at rebased/retargeted roots, still top4 per eligible object. Shared static global legality on every emitted sequence. Differences in candidate domains are part of B2/B4 mechanisms; log source task, prefix and rank for every action. A fixed-root D4 witness absence is not a global impossibility proof. No off-pool expansion as separate intervention.

Readouts for ordered local sequence c, endpoint s:
```
pY = sigmoid(b_s)
pX1 = sigmoid(a_c+w_c)
pX0 = sigmoid(a_c)
pX = pY*pX1 + (1-pY)*pX0
p11 = pY*pX1
```
`pX` is marginal local execution probability, not p11. In intermediate groups Y may be false despite indispensable moves. Never gate local feasibility on original-target Y or p11. For full endpoint E from original S0, `Y_global(E)` via Y-only `xy.make_view(...,y_edits=[...],x_seqs=[])`, get correct mapped endpoint node, not `y0`; no full-X call required. Cache by `(S0, canonical assignment)`. Separate diagnostic `Y_rebased(E)` = no-op probability of final scene treated as fresh original-task root; loses edit features. Primary original-root Y readout is OOD in edit count; final-scene readout is OOD in scene distribution. Do not switch after labels.

Chunk score for ordered full sequence r and partition pi=(c1,...,cj) with sizes 1–3, hypothetical prefix scenes Sj:
```
log H(r,pi)=log(max(eps,Y_global(E))) + sum_j log(max(eps,pX(cj | Sj-1,qref)))
eps=1e-8
```
This is a ranking heuristic, not calibrated P(success) or an independence theorem. For m≤3, retain exact frozen p11 rather than product, so B3 reduces to old scoring under complete enumeration. For m>3 use all TWO-group splits (4:1+3,2+2,3+1; 5:2+3,3+2), max H across partitions; all splits must be fully scored if admitting an order in the matched analysis. Keep chosen partition with plan, tie-break deterministic lexicographic after shorter length/lower displacement (match archived selector). Also compute bottleneck `Y_global*min(pX)` and Y_rebased alternatives on scored pool as diagnostics only; not additional physical arms or post-hoc selection. If desired report canonical 3+remainder as a model-only comparison. Do not reject partial plans solely on final Y being low. Shared frozen NOOP gate at original root; use eta on H as a declared heuristic admission threshold for composed m>3 (not calibrated to p11); log best candidate even if ABSTAIN, but no teacher evaluation of fallback in primary. Report length-specific score scales/admission bias (products may favor short plans). Retain original p11/no-op rule for B0/B1 and all short completed candidates. No tuning on 20 scenes.

### B4 — Fig. 3(a) recursive retargeting + insertion
This is not simply applying the original planner twice. It explicitly makes a pending relocation into a new temporary target action. Use the earlier 2D `Planner` only as conceptual reference; fix target feature layout and ensure actual prefix scene before each query. Work with a beam of global prefixes; retain multiple alternatives; deterministic branch limits. For each prefix P, generate local original-target hypotheses ≤3 via top4 requery and batched p11 (retain diversity; include low-p11 partials ranked by local marginal X and Y progress; never require final Y at this stage). For each local hypothesis u, process its pending actions in order. For each action a=(A,d):
1. Build exact pre-action scene S_P (including earlier insertions and local actions), retarget task `(A,d)`, reserve original target/goal, A, other pending objects/destinations, used objects and original occupancy. Compute temporary-target NOOP pY_temp, interpreted as predicted feasibility of executing A→d now. This is a learned proxy for full action feasibility, not proof. No teacher call.
2. If pY_temp < 0.5, or the lowest-ranked action of that hypothesis has pY_temp <0.9, try enabling repair hypotheses up to min(3, remaining global budget minus pending actions). Thresholds are fixed starting defaults, not tuned on fresh data. Evaluate local temporary-task p11 for ranking completed enabling sequences; keep top diverse alternatives and optionally a progress branch; no need for original-task Y to be true. If an enabling action itself looks blocked, recursively retarget it (depth≤2, cycle guard `(prefix,task,reservations)`, global length cap 5). Use original-target exclusion and pending reservations throughout. Recompute temp Y on actual hypothetical pre-action scene after enabling edits; accept inserted branch if temp Y≥0.5, or strictly improved by a fixed ≥0.10 as explicitly labelled relaxed branch; record before/after, avoid treating as physical success. Keep no-insertion sibling even if score low, so noisy gate doesn't veto all routes. No witness identities or static kill tables.
3. Insert e immediately before A→d, append a, enforce global grammar, update actual prefix. Dedup sequence, log tree/parent/depth, budget and reservation decisions. Recursion always consumes room or terminates; never allow A to move twice, move original target, steal a reserved destination, or recurse endlessly. If room is zero, keep original candidate and mark no enabling room. If no candidate found, do not claim infeasibility. Preserve multiple endpoints / short partials as frontier even if original Y is low, expand on new original-target local hypotheses until no candidates, cap or length5. No silent first-success stopping that prevents other candidates within budget.
4. Pool resulting assignments and recorded insertion orders; final ranking uses same B3 global Y + short-horizon H. To preserve enabling-before-parent structure, keep insertion order and enumerate only orders respecting recorded prerequisite edges; include at least original insertion order, all legal linear extensions if budget fits. Also run unconstrained permutations on same assignment as model-only diagnostic (does learned edge constraint help/hurt?). If same assignment comes from different dependency graphs keep each graph/order trace and dedup scored orders. For primary B4 use recorded dependency-respecting orders only and declared two-group splits; all intermediate groups retain all objects. Retargeting predictions are OOD, no causal attribution guarantee.
5. Final decision one plan; no physical feedback to expand. Fig. 3's 'expand if insufficient' means **predicted** insufficiency / learned candidate budget in primary. Any post-physical fallback is out of scope. Log cases with actual insertions vs B4 merely flat, witness recall, added object identities after seal and whether insertion physically helped.
