### 0.4 Main paper metrics — formal definitions (do not change late)

Let `Z(r)=1` iff finalized **X=1 AND Y=1** for proposed correction `r` under the pinned protocol. Evaluate candidate-prediction metrics only on a **shared, held-out, physically labeled candidate set**, not each method's own favorite proposals.

- **AUC ↑ (3D):** AUROC of a *pre-execution continuous score for Z*, on the shared held-out candidate set. For Approach B use `p11`. If a baseline has no admissible candidate-level score before low-level physical checking, report **N/A**, not fabricated probabilities, physical planner success recast as learned prediction, or zero. A ranking score may be used for AUROC if its direction/meaning is declared; it is **not** thereby a calibrated probability.
- **NLL ↓ (2D):** binary joint-success log loss `-Z log p11 -(1-Z)log(1-p11)` on the **same frozen candidate pool** for D/E/G/DIRECT. This is distinct from the **full root-consistent X/Y observed-data joint NLL used to train/evaluate D/E/G**. Report full X/Y NLL, Brier and reliability plots in supporting diagnostics, not as additional Table I columns. For variants that retain the *identical frozen predictor*, show `—` (unchanged/not the manipulated component) or a clearly labeled repeated reference value consistently.
- **Order ↑ (2D):** accuracy for *matched-endpoint permutations with different finalized X outcomes*, using the subset with **Y=1** for fair comparison to DIRECT's `p11`. Does the model rank the executable ordering above the nonexecutable ordering? Ties receive 0.5; report number of evaluated pairs and root-clustered uncertainty. The Y=0 order contrasts may be reported separately using `pX`, but not silently mixed into this column.
- **Repair ↑:** physically verified **minimal-repair success (%)** on *initially infeasible, solvable tasks with a finalized-protocol-certified minimal K*. A different set of objects/destinations is allowed if its correction succeeds and has exactly K* relocations. A construction-intended K or legacy label alone is **not** proof of minimality. Ambiguous K* cases must be excluded from this denominator or reported with a clearly defined *verified-relative* criterion. Disclose denominator and coverage.
- **Task ↑:** independently verified success of the **original target task after the selected physical correction**, using any allowed number of relocations `0..Kmax` even when not minimal. Use the same solvable, initially infeasible roots as Repair for the primary comparison. Selected-without-execution is **not** success.
- **Time ↓:** elapsed wall-clock **end-to-end online planning time**, from receipt of root to repair/abstain, including sampler calls, neural inference, search, and any low-level planning the baseline needs *during selection*; excludes offline training and the final standardized evaluation verifier. Report timeout/censoring treatment and hardware alongside mean or median.
- **Calls ↓:** number of *actual online motion-planner/physical teacher calls used in the method's decision process*, with a precise common counter boundary. Counting raw neural scores as MP calls is wrong. Final independent verifier calls are reported separately, not blended into this metric. Zero planning-stage calls for a frozen learned-only search may be real, but the final verifier cost must still be disclosed.
- **Travel ↓ (2D):** actual normalized robot joint-space travel on **successfully executed repairs**, using one frozen full-witness definition. Report success alongside travel; add a paired common-success-root travel analysis so methods cannot appear economical simply by failing difficult tasks. `Travel` is **not** predicted `J_hat`.

**Other outcome strata** (report outside Table I): K0 correct no-op, NONE correct abstention, K1/K2/K3, K3 1/6–6/6 order strength, hard-order and natural-assignment views, model calibration, sampler coverage, no-repair/unknown statuses, and per-stage failure causes. Treat the hard and natural views derived from the same roots as **different assignment views, not independent test scenes**.

## 1. Frozen scene, labels, and module interfaces

### 1.1 Typed root and correction

For each immutable root use

\[
R=(S_0,q_0,q_{\mathrm{ref}},T,g_T,\mathcal O,\mathcal F,\Pi,\mathcal B),\quad
r=[(o_1,d_1),\ldots,(o_m,d_m)],\quad 0\le m\le 3.
\]

- `S0`: objects, identities, shapes, poses, fixed geometry and supports; `q0`: initial robot state; `q_ref`: **fixed** target-reference configuration; `T,gT`: original target/task and goal; `Pi,B`: pinned robot and physical finite-budget conventions.
- The target pick/transfer/place **is not counted** among the maximum three corrective relocations.
- Each corrected object is moved at most once; destination grammar forbids initially occupied slot swaps, repeated or overlapping placements, support violations, and fixed-geometry penetration. Do not silently change this action grammar for the baselines.
- `S_r = Edit(S0,r)` is a hypothetical **object pose** state only. It carries **no guessed achieved robot configuration**; the full order and **original** `(S0,q0,q_ref)` remain inputs to the X side of the scorer.

### 1.2 The two labels are separate physical questions

- **X=1** only if ordered corrective relocations execute from original `(S0,q0)`, carrying actual robot/gripper configuration between moves, and then a **free-gripper connector to `q_ref` succeeds**. A terminal connector failure when stopping after A does **not** imply every extension AB is impossible.
- **Y=1** only if the original target is independently achievable from `q_ref` in endpoint `S_r` under the final teacher protocol. If AB and BA have the same endpoint assignments, Y is **shared**, even when X differs.
- `Z = X and Y` is a derived complete-repair success label; do not replace the physical X/Y evidence with legacy complete-task success.
- `MISSING` (unattempted, timed out administratively, cancelled, censored) is not a zero. An attempted finite-planner-budget failure is a policy-relative zero with pinned budget, seed, failure stage and witness provenance.

### 1.3 Fixed interfaces

| Component | Inputs | Output | Responsibility boundary |
|---|---|---|---|
| `placement` | Hypothetical scene, chosen object, support domain, RNG and budget | Distinct legal destinations + provenance | Does *not* choose blocker/order, infer X/Y, run target planner |
| `xy` | Original root, **whole ordered candidate**, endpoint | `pY,pX,pX_givenY,p11`, optionally `J_hat` | Does *not* sample actions or execute motions |
| `search` | Original root, frozen sampler/scorer, resource caps | Candidate prefixes, ranked stopping repairs, abstention | Edits objects hypothetically; never calls physical teacher in learned inference |
| `cost` | `p11`, move count, analytic displacement, learned travel | Stopping cost/rank | Cannot treat a prefix's stopping cost as descendant lower bound |
| `execution` | Selected ordered repair and original physical root | Actual correction and target verification | Independently verifies only the selected repair during evaluation |

### 1.4 Canonical identity and cache contract

- `x_key=(root_hash, robot/teacher/budget hashes, q0, q_ref, exact ordered (object,destination) sequence, connector protocol)`.
- `y_key=(root_hash, target/goal, endpoint_scene_hash, q_ref, target teacher/budget hashes)`. **Same endpoint and goal ⇒ same Y.**
- `place_key=(scene_hash, object, destination, support/grasp/teacher version)`.
- `proposal_cache=(hypothetical_scene_hash, object, sampler version, budget, seed, legality version)`.
- Do not merge AB and BA in the X cache, or merge two goals in the Y cache. Deduplicate Y per genuine endpoint; root-consistent Y must not depend on how many alternatives are queried.

**Unit gates:** no-op has no relocations; serializing a root preserves geometry; AB/BA share endpoint Y but have distinct X; target-goal changes alter Y features/key; cross-branch edits never mutate sibling or root state; a missed query remains missing.

## 3. P1 — Conditional placement proposals (cVAE first)

### 3.1 Precisely what placement learning does

- **Condition:** `(scene S, selected object o, declared support/placement domain, post-grasp capability convention)`. **Exclude target/goal, intended repair, certified blocker list and labels**. The sampler assumes the object is already held; its output does **not** certify pick access or multi-action execution.
- **Supervision:** existing isolated Q2 physical placement trials. `V_place=1` iff that object's standalone carry/place/release under the pinned convention succeeds. Administrative failures are missing, not negative.
- **Output:** destinations for *one selected object*, not object-selection, ordering, full repair or Y. The search iterates eligible objects and forms `(o,d)` actions.
- 2D: finite resting-position lattice with articulated-arm physical motions. 3D: support-constrained physical shelf with finite cell/upright-pose set if that is how the actual data is encoded; do not claim unconstrained SE(3) generation.

### 3.2 cVAE architecture and training objective

Use condition embedding `c=f(S,o)`. During training, an encoder sees a **successful destination** and condition; a decoder maps latent plus condition back to the destination:

\[
q_\psi(z\mid c,d^+),\quad p_\phi(d\mid z,c),\quad
\mathcal L_{\mathrm{cVAE}}=
\mathbb E_{q_\psi}[-\log p_\phi(d^+\mid z,c)]
+\beta_{\mathrm{KL}}D_{\mathrm{KL}}(q_\psi\Vert\mathcal N(0,I)).
\]

- Use masked **categorical** destinations for discrete legal cells, with explicit support/pose modes if required. Do not regress the average of multiple successful modes as if it were a feasible location.
- At inference, sample `z~N(0,I)`, decode conditional destinations, apply common static legality, deduplicate and log raw vs unique proposals. The posterior encoder **does not** see an unknown successful destination at inference.
- Track latent utilization, duplicate rate, region coverage, sample latency, invalid outputs and evidence of posterior collapse. Candidate frequency/density **is not** calibrated probability that `V_place=1`.
- No test-time IK, physical teacher call, target trajectory/sweep, or target repair catalogue in proposal filtering.

### 3.3 Exactly two primary sampler controls for Table I(b)

1. **Analytical sampler:** choose a *frozen validation-selected* transparent analytical placement proposal policy (e.g., uniform/Sobol or near/mid/far band-stratified if strongest). Give it the same legal supports, *unique legal proposal* budget and search/scoring budget as cVAE. Keep any privileged target-swept-volume policy out of this comparison unless its inputs are explicitly matched and disclosed.
2. **Conditional flow matching:** train a conditional velocity field using the same `(S,o)` information and placement positives, sample with an audited ODE scheme, project to legal supports, deduplicate and account for solver steps/latency. If the decoder is discrete, define and validate a proper continuous-to-cell mapping; no silent unfair extra draws.

**Other sampler checks** (optional supporting experiments, not extra main ablation rows): z-disabled categorical model, placement confidence ranker on/off, separate uniform and band controls, precision/diversity per placement distance, `M` sweeps, previously unseen destination queries. Keep the baseline selected by validation, not by final test success.

### 3.4 Standalone sampler evidence and gate

- `sample(S,o,M,seed)` returns deterministic provenance and a list of distinct statically legal destinations for a fixed seed and budget. It can be swapped with the analytical and flow-matching adapters **without changing search**.
- Physically checked placement hit@M/precision, unique feasible coverage, distinct regions, duplicate/legal rate and latency must be measured on specified predeclared roots/queries. A subset of previously measured positive placements is **not** unbiased true precision; separate checked positives/negatives/unknowns.
- Plot at least one labeled 2D placement grid with successful/failed/unknown destinations and generated proposals; analogous 3D shelf support map; and success hit@M versus proposal budget.
- Train/validation-only model selection; minimum one smoke run before multi-seed final fits. Archive checkpoints and full sampler snapshots by dataset hash.

**P1 gate:** swappable, frozen cVAE/analytic/flow placement samplers with matching static checks, no privileged input, known proposal latency and auditable standalone success/coverage.

## 4. P2 — Root-consistent coupled X/Y Boltzmann learning

### 4.1 Outputs, factors, and normalized probability

Let `s(r)` be the hypothetical endpoint of `r`. The model produces three **real logits/coefficients**:

\[
b_s=h_Y(\text{endpoint},T,g_T,q_{\rm ref},\text{root context}),
\quad a_r=h_X(\text{root},q_0,\text{ordered }r),
\quad w_r=h_{XY}(\text{root},\text{ordered }r,\text{endpoint}).
\]

Interpret `F3` as the Y-unary `b_s`, `F2` as the ordered X-unary `a_r`, `F5` as the X/Y coupling `w_r`. Use **root-consistent scene-first normalization**:

\[
P(Y_s=1)=\sigma(b_s),\qquad
P(X_r=1\mid Y_s=y)=\sigma(a_r+w_r y).
\]

For a set of scored candidate orders/endpoints from one root:

\[
P(\mathbf Y,\mathbf X\mid R)
=\prod_{s}P(Y_s)\prod_rP(X_r\mid Y_{s(r)}).
\]

Then

\[
p_{11}(r)=\sigma(b_{s(r)})\sigma(a_r+w_r),\qquad
p_X(r)=\sigma(b_s)\sigma(a_r+w_r)+[1-\sigma(b_s)]\sigma(a_r).
\]

**Never** substitute a naive independent product `P(X)P(Y)` or separately normalize four states *per candidate* so that adding AB/BA alternatives changes the same endpoint's `P(Y)`. A raw local factor energy `-(a_r x+b_s y+w_rxy)` alone is **not** the correct normalized root likelihood: the Y-dependent X normalizers matter.

### 4.2 Encoder/input constraints

- `F3` **must see target identity and exact goal**, support/fixed scene geometry and `q_ref`. A 3D Y encoder that sees only endpoint object layout but not `T,gT` is incorrect.
- `F2` **must see original scene/root, original `q0`, exact ordered object–destination actions** and predecessor-sensitive information. Encodings may use the verified GRU/attention and GEO2-style geometric features; do not manufacture an intermediate achieved robot state.
- `F5` couples the proper sequence and endpoint contexts. It cannot be replaced with an unannounced independent classifier.
- Use a real empty-sequence path and label convention; no empty-RNN crash. Missing outcomes never appear as model inputs.
- `F1` deterministic static legality is shared outside the learned factors; `F4` refers to omission/intervention evidence using these **same** X/Y outputs, not a fourth new predictor.

### 4.3 The **four** factor-architecture arms, matching the paper

| Arm | Table I(b) label | Required controlled change |
|---|---|---|
| **D — full** | Full approach (`F2,F3,F5`) | Ordered X + goal-conditioned Y + learned coupling; fixed full features |
| **E — uncoupled** | Uncoupled (`F5=0`) | Set `w_r=0`; retain F2 and F3, matched data/features/search and comparable capacity/compute |
| **G — order-invariant** | Order-invariant (`F2,F5`) | Make sequence/order-sensitive inputs of F2 and F5 order-blind; retain comparable endpoint and geometric inputs; verify AB/BA invariance at identical endpoints |
| **DIRECT — direct success** | Direct success predictor | Replace the explicit X/Y factors with `pZ=σ(f(root,ordered r,endpoint,T,gT))`; same ordered features and candidate evidence. Do not intentionally cripple this classifier or pretend it predicts separate X/Y |

These three ablation rows **already provide the main factor-graph justification**: E tests coupling, G tests ordering, DIRECT tests explicit factorization vs a direct whole-repair predictor. Do **not** add a no-geometric-features row or F2/F3 individually removed rows to the paper table. Goal sensitivity and factor connections are **invariant/unit tests** and supplementary error analyses.

### 4.4 Exact observed-data training loss

For each root, deduplicate observed X queries by exact `x_key` and Y by `y_key`; group all X orders sharing endpoint `s`. With `O_X(s)` the observed X labels at endpoint and `Y_allowed(s)` either the observed Y or `{0,1}` when Y is missing:

\[
\ell_s=-\log\sum_{y\in Y_{\mathrm{allowed}}(s)}
P(Y_s=y)\prod_{r\in O_X(s)}P(X_r=x_r\mid Y_s=y).
\]

Use `L_joint = mean_per_root(sum_s ell_s)`, stable logsumexp/logsigmoid/softplus, proper masking and **one** Y term per unique endpoint. If Y is missing, marginalize it; if X is unobserved, omit that term. Exclude roots with zero observed evidence explicitly. Never fill unknown labels with zero or weigh a root more merely because its catalogue was queried more often.

**DIRECT** trains on the observed derived binary `Z=X∧Y` where both labels exist (and on provably determined cases if the documented masking logic permits). Match training roots/queries fairly and disclose label coverage differences; do not call its binary loss “full joint X/Y NLL.” Calibrate all available probabilities on validation only.

### 4.5 Prediction tests before fitting and after fitting

1. Synthetic tiny-root brute-force enumeration matches every marginalized probability, loss and gradient within numerical tolerance.
2. Adding an AB/BA alternative does not change endpoint `P(Y)`; same endpoint with reversed order may change `P(X)`.
3. Change goal while freezing endpoint: F3 input changes and learns goal-sensitive Y; changing order with same endpoint changes D's F2/F5 features; G is deliberately order-invariant.
4. All four `(X,Y)` quadrants; Y missing; X missing; no-op; multiple X per endpoint; duplicate source keys; censored outcomes; gradient flows to each factor head.
5. Toy learnability and reproducible training checkpoints before full data fitting; then use actual finalized train/validation roots for D/E/G/DIRECT, **same candidate sets, seed schedule, source evidence and early-stop rules**.
6. Freeze model selection by validation full observed-data NLL (D/E/G) or an explicitly declared comparable binary-Z NLL (cross-arm comparison). After freezing, publish **binary Z NLL** and **paired-order accuracy** for Table I(b); full X/Y root NLL, Brier, calibration, XY decomposition and confidence intervals in supplementary diagnostics.

**P2 gate:** mathematical normalization and input schemas verified, D/E/G/DIRECT genuinely trained on comparable evidence, held-out binary-Z prediction measured, goal/order contrasts externally grounded, and no test data used to choose the winner.

## 5. P3 — Physically witnessed joint-travel cost and selector

### 5.1 Freeze cost target before training

The latest authoritative methodology favors **complete successful witnessed joint travel**: corrective approach/carry/release, between-action transitions, terminal `q_ref` connector, and actual target task. Earlier methodology versions used relocation-only travel. These targets must **not** be pooled into one loss without explicit decomposition and protocol reconciliation.

Audit witness support and record `J_reloc`, `J_connector`, `J_target`, `J_complete`, normalization, joint conventions and teacher/witness seed. Use `J_complete` for the primary `Travel` metric and learned `J_hat` **only if evidence exists**. If the final snapshot provides relocation-only travel, flag the incompatibility; do not invent complete target travel or silently shift the paper metric. A model head predicts **the witnessed teacher-policy cost**, not globally optimal path cost.

### 5.2 Fitting, masks and ranking

On appropriate successfully executed complete witnesses only:

\[
\hat J_r=\operatorname{softplus}(h_J(\text{root},r,T,g_T)),\qquad
\mathcal L_J=\operatorname{mean}\,\operatorname{Huber}
\big(\log(1+\hat J_r),\log(1+J_r)\big).
\]

Travel labels are **masked when absent**, never zero or infinity. If the travel readout shares features with the X/Y network, document any auxiliary `lambda_J L_J` contribution and match predictor arms fairly. If training independently, record the independent objective. Choose loss weights using validation only.

For each *stopping* candidate:

\[
C(r)=-\log\max(p_{11}(r),\epsilon)
+\alpha |r|+\beta D(r)+\gamma\hat J_r.
\]

Here `|r|` is corrective relocation count; `D` is **analytic object displacement** with declared cell-vs-metric normalization; only `J_hat` is learned. Freeze all coefficients, no-op threshold, feasibility threshold `eta`, epsilon and tie breaks on validation. Low travel must **not** compensate for `p11<eta` where eta is enforced.

### 5.3 Exact Table I(b) cost ablation

- **No travel-cost term:** set **gamma=0 at inference**, leaving cVAE, D, learned predictor parameters, candidate generation, search budget, `alpha`, `beta`, `eta`, and all thresholds unchanged. Keep `J_hat` head frozen if already trained; do not retrain a different XY model for this row.
- **Full approach:** identical pipeline with validation-selected `gamma>0` if supported and beneficial. Avoid pre-committing to a positive coefficient when witness coverage is insufficient; report a null result transparently.
- Report **Task success and Repair success alongside actual Travel**. A full-cost policy that succeeds on fewer scenes may have lower conditional mean travel for misleading reasons; report common-success paired travel or a success–travel Pareto plot in supplementary evidence.

**P3 gate:** witness metric fixed and auditable, head fit on real data without missing-label corruption, cost units compatible, gamma-off row reproducible from the same frozen model and search apparatus.

## 6. P4 — Branch-local dynamic search and the one-shot ablation

### 6.1 Single operational loop

Every node is a *proposed ordered prefix*, not a physically executed intermediate state:

```text
root = immutable (S0, q0, q_ref, T, goal, protocol)
frontier = [empty_prefix]; stopping = [score_no_op_from_Y(S0)]

while frontier nonempty and search budget remains:
    r = pop_by_frozen_fair_best_first_policy(frontier)
    if length(r) == 3: continue
    S_r = Edit(S0, r)                   # hypothetical objects only
    children = []
    for eligible object o not moved in r:
        proposals = sampler.sample(S_r, o, M, seed)  # RE-QUERY every branch
        for d in static_legality_and_unique(proposals):
            children.append(r + [(o, d)])
    scores = xy_scorer.batch_score(original_root, children,
                                  endpoints=[Edit(S0,c) for c in children])
    for child, score in zip(children, scores):
        log(pY, pX, pX_givenY, p11, J_hat, move_count, displacement, cost)
        stopping.append(child)         # every prefix is a stopping candidate
        if length(child) < 3: frontier.insert(child)

choose cheapest eligible stopping candidate by frozen no-op/eta/cost rule
if none accepted: ABSTAIN/UNKNOWN (not an impossibility proof)
execute selected ordered repair FROM ORIGINAL physical root
independently verify ordered correction and original target task
```

`xy_scorer` **always** sees `(original S0,q0,q_ref,T,goal,whole ordered r,endpoint)`; not `(hypothetical S_A,B)` as an achieved new robot start. Never physically test every proposal to perform oracle filtering in Approach B. Cache exact X scores, deduplicate endpoint Y, batch expensive neural inference, record raw vs unique samples and expansion counts.

**Search control** (which prefix to expand) is distinct from **stopping cost** (which completed correction to select). A prefix whose Y is currently low might produce a successful longer correction; never prune it solely by stopping `pY` or connector failure. Honor max K=3, at-most-once per object and predeclared fairness/resource caps. Do not claim global completeness with finite stochastic sampler coverage.

### 6.2 The **only primary search ablation**: One-shot selection

Compare **full iterative search** with **one-shot repair selection**, holding everything else constant:

- **Iterative:** propose destinations conditioned on `S_r=Edit(S0,r)` at every branch; score new ordered prefixes with the same frozen Boltzmann model; expand under the same fairness/budget protocol.
- **One-shot:** sample **all object destinations only from initial `S0`**, then construct and rank up-to-K ordered candidate repairs using those fixed proposals. Evaluate each resulting prefix with identical hypothetical static legality, endpoint features, D prediction, travel head and stopping cost. **No re-query after hypothetical edits.** It must still consider order alternatives; it is not a straw-man greedy single-move baseline.
- **Budget parity:** same maximum unique legal placements, scorer evaluations, frontier expansions, total raw sampling/duplicate accounting and wall-clock cap where possible. One-shot cannot receive an unlimited initial candidate catalogue; iterative cannot receive extra uncounted proposals at every depth. State any unavoidable mismatch and perform a matched-budget sensitivity plot.
- **Do not confuse** the one-shot ablation with training/using a new order-prediction oracle, initial intended-repair assignment, or static scene replay from a ground-truth catalogue.

### 6.3 Non-negotiable regression scenes

1. A placement for B becomes available (or more probable) only after a hypothetical A move; iterative re-query finds it, one-shot can miss it.
2. AB vs BA same final scene: Y shared, X distinct, both orders retained by caching/search.
3. A stopping repair is Y=0, extension AB yields Y=1, so expansion remains possible.
4. A terminal connector failure when stopping after A does not preclude expansion AB.
5. Sampler generates a legal-looking physically failing relocation; model/teacher handles it as X failure, not sampler-certified success.
6. No-op scenario and harmful extra relocation; correct no-op threshold behavior.
7. Immutable sibling branches; no environment reset assumed for physical action-order semantics.
8. Exactly three corrections allowed; target action excluded from count; fourth rejected.
9. Fixed seed + deterministic tie breaks + batch/cache/checkpoint resume reproduce ranking under the declared schedule.
10. Proposal miss, score misranking, search exhaustion, teacher censoring and selected-but-unverified outcomes are classified distinctly.

**P4 gate:** validated iterative re-querying, faithful one-shot comparator with matched resources, correct X/Y root arguments, bounded budget, reproducible selected plans and honest unknown/abstain statuses.

### 9.2 Aggregation rules

- **Prediction candidate cohort:** require **both X/Y observed** for binary Z; include failures and successes. Score D/E/G/DIRECT on identical candidates. Confidence intervals resample **roots**, not permutations/assignments as independent observations.

- **Repair:** denominator contains *verified minimal K* under the final X/Y protocol; if only restricted-grammar minimum is certified, name it as such and never imply global minimal robot actions. A shorter Y=1 omission without X=1 does not disprove minimality.
- **Task:** count `FOUND_VERIFIED` only; cannot count `SELECTED_UNVERIFIED` as success. Compute timeouts/missing separately.
- **Travel:** success-conditional physical metric, normalized by declared robot joints; additionally compare common-success roots and report their number. Do not fill travel 0 on failures.
- **Calls/time:** count sampler, neural, search and physical baseline queries honestly; never exclude a baseline's internal planner calls while charging them to others. Present final verification separately.
- **Failure modes:** `SAMPLER_MISS`, `MODEL_MISRANK_X`, `MODEL_MISRANK_Y`, `SEARCH_BUDGET_UNKNOWN`, `PHYSICAL_EXEC_FAILURE`, `TARGET_FAILURE`, `CONNECTOR_FAILURE`, `TEACHER_CENSORED`, `ABSTAIN` with versioned and non-overlapping definitions where possible. One failure may need multiple diagnostic tags; choose a declared primary cause rule.
- **Statistics:** at least root-clustered paired bootstrap intervals for differences; fixed training seeds and transparent effective sample counts; no selectively reporting only favorable 1/6 or highly biased hard-order subsets.

## 12. Scientific failure rules and claims we must not make

- **A cVAE generates individual plausible placements, not a certified feasible action set or causal object list.** Search decides who to move; X/Y predicts full repair success. Its density is not `P(V_place=1)`.
- **Coupling is a hypothesis.** D is not guaranteed to outperform E or DIRECT. Explicit F5 improving classification is not proof of a directed causal edge. Physical order/omission interventions support limited causal contrasts, not an identifiable causal DAG.
- **Order matters physically.** Same endpoint can have shared Y and different X because of sequential robot motion; 2D and 3D results must be tested with the pinned robot protocol, not just geometric slot availability.
- **A predicted repair is not an executed repair.** The high-level method proposes an ordered correction; the external motion planner/controller realizes it. Do not claim the learned model generates continuous trajectories.
- **Operational finite-budget failure is not universal impossibility.** A capped search can abstain or miss a proposal even on a solvable root. Report coverage/unknown, do not reclassify roots as mathematically impossible.
- **Minimality needs finalized proof.** Construction K, legacy K, and a shortened Y=1 omission are insufficient without X. Count uncertain cases transparently.
- **No training/validation/test leakage.** Scene root, sibling parking assignments, order permutations, hypothetical descendants, teacher witnesses and cached plans travel together as a split/lineage unit. A deliberately hard test view and its natural-assignment sibling are **not** separate independent test observations.
- **No unsupported baseline claims.** RRT-Connect is not an autonomous repair planner; PIGINet is not an end-to-end repair planner without TAMP; retrieval/grasping and pushing papers need explicit adaptation to our task. Baseline comparability and checkpoint/teacher access must be established, not asserted.
- **No hidden cost switching.** `J_reloc` and `J_complete` are not interchangeable; measured Travel is not predicted J; failures do not have zero travel by imputation.
- **No figure overclaiming.** Diagrammatic arrows and hypothetical scenes are not evidence of robot execution. Publication figures need ground-truthed labels and separate predicted/executed visual indicators.
- **Two opposed shelves:** future extension requiring source retrieval, 180° target transfer, destination placement and joint verification. Not required for either Table I panel or this implementation freeze.
